# HackVerse Cyberpunk Theme

A dark, technical, cybersecurity-themed CTFd theme. Built as a Jinja2 + Vite + SCSS CTFd theme (not a standalone SPA), so every existing CTFd flow — login, registration, challenges, flag submission, hints, scoreboard, teams, users, notifications, admin — keeps working exactly as it does in stock CTFd.

## Design

- **Palette**: near-black surfaces (`#050505` / `#0D1110`), neon green (`#00FF88`) and cyan (`#00D9FF`) accents, a subtle purple (`#B084FF`) for crypto/secondary accents.
- **Typography**: system UI sans-serif for normal content, a monospace stack (`JetBrains Mono` / `Fira Code` / system monospace fallback) for terminal output, flags, and technical metadata.
- **Motion**: an animated canvas "network" background (drifting nodes, connecting lines, mouse interaction — a lightweight hand-rolled equivalent of the Vanta.NET look), a cursor spotlight, magnetic/tilt card hover, scanline film, sparing glitch-text on the hero heading, and a one-time boot/loading sequence — all gated behind `prefers-reduced-motion` and reduced on touch/mobile devices.
- **Hero terminal**: a cosmetic, sandboxed terminal widget on the homepage. It never executes real commands — it matches a small fixed command whitelist (`whoami`, `system-status`, `ls`, `date`, `clear`, `./enter_ctf`) and prints canned output built from the logged-in user's real session data (`window.init`), not hardcoded demo values.
- **Live stats**: the homepage stat tiles (challenges / solves / players) are populated from the CTFd API at runtime and animate in with an `IntersectionObserver` counter — there is no hardcoded team/solve count anywhere in the theme.

## Stack

- Jinja2 templates (`templates/`)
- Vite + SCSS (`assets/scss/main.scss`) — Bootstrap 5 variables are overridden to the cyberpunk palette
- Vanilla JS modules under `assets/js/theme/cyberpunk/` for the background canvas, spotlight/tilt, glitch text, terminal, stat counters, and loading screen
- Alpine.js for the existing CTFd interactive components (challenge board, scoreboard, hints)

## Development

```bash
yarn install
yarn dev     # vite build --watch
yarn build   # production build into static/
```

### Install into CTFd

```bash
git clone <this-repo-url> CTFd/themes/hackverse
```

Then select the theme from the CTFd admin panel's theme settings.

### File structure

```
assets/
├── img/                       # Images and SVG assets
├── js/
│   └── theme/cyberpunk/       # Background, spotlight, glitch, terminal, counters, loading
├── scss/
│   └── main.scss              # Design tokens + all component styling
templates/
├── base.html                  # Shell: loading screen, background layers, navbar, footer
├── page.html                  # Renders admin-authored pages; adds the hero+terminal on "/"
├── challenges.html            # Challenge board
├── challenge.html             # Challenge modal
├── scoreboard.html            # Scoreboard + challenge completion matrix
└── components/                # Navbar and other shared partials
static/                        # Compiled assets (generated by `yarn build`)
```

## Accessibility & performance

- Respects `prefers-reduced-motion`: the network background, spotlight, tilt, glitch, and scanline effects are all disabled or skipped.
- Canvas background and pointer tracking are throttled to `requestAnimationFrame`, capped on mobile, and torn down on `pagehide`.
- Focus-visible outlines, semantic HTML, and existing CTFd ARIA labeling are preserved.
